# AI Помощник iPhone v2

Новая версия PWA-ассистента для iPhone.

Возможности:
- современный интерфейс;
- тёмная/светлая/авто тема;
- быстрые действия: спросить, объяснить, написать, сократить, перевести, учёба, идеи, код;
- готовые шаблоны;
- локальная история;
- голосовой ввод при поддержке браузера;
- чтение текстовых файлов;
- отметка фото/PDF/других файлов для дальнейшего прикрепления в ChatGPT;
- копирование запроса;
- PWA и добавление на экран «Домой».

Важно: это PWA, а не нативное iOS-приложение и не настоящая Safari Web Extension. Оно не хранит API-ключи и не использует собственный сервер.
